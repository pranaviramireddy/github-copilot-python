# Copilot Instructions

You are assisting with a Python Flask Sudoku project.

Follow these rules:

- Use modern Python 3.12+ features where appropriate.
- Write modular, reusable functions.
- Separate game logic, UI logic, and utility functions.
- Prefer readability over clever code.
- Add comments only when they improve understanding.
- Handle exceptions gracefully.
- Use descriptive variable names.
- Avoid duplicated code.
- Keep functions short and focused.
- Follow PEP8.
- Preserve existing functionality unless intentionally refactoring.
- Explain major code changes before suggesting them.
- When adding features, do not break existing tests.
- Prefer Flask best practices.
- Suggest responsive HTML and CSS.
- Ensure compatibility with dark mode.
- Keep accessibility in mind.
